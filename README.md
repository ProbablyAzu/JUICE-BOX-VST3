# JUICE BOX

### PURE ACID. NO SWEETNESS.

**JUICE BOX** IS AN INDEPENDENT VST3 KICK SYNTHESIZER CREATED BY **AZXNA**, DESIGNED FOR PRODUCERS WORKING IN JUMPSTYLE, HARD TECHNO, HARDCORE AND HARD DANCE.

BUILT AROUND THE IDEA OF MAKING KICK DESIGN MORE DIRECT, POWERFUL AND CREATIVE, JUICE BOX AIMS TO BRING SYNTHESIS, DISTORTION, TRANSIENT SHAPING AND DETAILED SOUND DESIGN INTO ONE DEDICATED AUDIO PLUGIN.

THE GOAL IS SIMPLE: GIVE PRODUCERS THE TOOLS TO CREATE THEIR OWN SOUND FROM THE GROUND UP.

---

## PROJECT OVERVIEW

JUICE BOX IS BEING DEVELOPED AS A NATIVE WINDOWS VST3 PLUGIN WITH A CUSTOM SOUND ENGINE AND A DISTINCTIVE USER INTERFACE.

RATHER THAN FUNCTIONING AS A SIMPLE SAMPLE PLAYER, THE PROJECT IS BUILT AROUND ACTUAL KICK SYNTHESIS. USERS WILL BE ABLE TO SHAPE THE FUNDAMENTAL SOUND, CONTROL PITCH MOVEMENT, DESIGN TRANSIENTS AND APPLY AGGRESSIVE PROCESSING TO CREATE THEIR OWN KICKS.

THE PLUGIN IS SPECIFICALLY INSPIRED BY THE SOUND DESIGN REQUIREMENTS OF HARD DANCE MUSIC, WHERE THE KICK IS OFTEN THE CENTRAL ELEMENT OF THE ENTIRE TRACK.

## DESIGN PHILOSOPHY

- **SOUND FIRST:** PRIORITIZE SOUND QUALITY, FLEXIBILITY AND CREATIVE CONTROL.
- **PURPOSE-BUILT:** FOCUS ON THE NEEDS OF JUMPSTYLE, HARD TECHNO, HARDCORE AND HARD DANCE PRODUCERS.
- **SYNTHESIS OVER SAMPLES:** BUILD KICKS FROM THE GROUND UP, WITH OPTIONAL SAMPLE LAYERING.
- **FAST WORKFLOW:** MAKE COMPLEX SOUND DESIGN ACCESSIBLE THROUGH A CLEAR AND INTUITIVE INTERFACE.
- **PERFORMANCE CONSCIOUS:** DEVELOP AN EFFICIENT AUDIO ENGINE SUITABLE FOR REAL-TIME PRODUCTION.
- **DISTINCT IDENTITY:** CREATE A PLUGIN THAT FEELS AS UNIQUE AS THE SOUNDS IT PRODUCES.

## PLANNED FEATURES

THE FOLLOWING FEATURES REPRESENT THE PROJECT'S DEVELOPMENT DIRECTION. THEIR AVAILABILITY WILL DEPEND ON IMPLEMENTATION AND TESTING.

### 01 / KICK SYNTHESIS

A DEDICATED SYNTHESIS ENGINE FOR GENERATING KICKS WITHOUT RELYING ENTIRELY ON PRE-RECORDED SAMPLES.

- FUNDAMENTAL OSCILLATOR
- FREQUENCY AND PITCH CONTROL
- PITCH ENVELOPE DESIGN
- BODY AND TAIL SHAPING
- DECAY AND AMPLITUDE CONTROL
- CUSTOMIZABLE KICK CHARACTER

### 02 / TRANSIENT DESIGN

DETAILED CONTROL OVER THE ATTACK AND INITIAL IMPACT OF EACH KICK.

- CLICK AND TRANSIENT SHAPING
- ATTACK CONTROL
- BODY CHARACTER
- TAIL CONTROL
- LAYER BALANCING

### 03 / DISTORTION AND SATURATION

A CORE PART OF THE JUICE BOX SOUND DESIGN PHILOSOPHY.

PLANNED PROCESSING OPTIONS INCLUDE:

- SOFT CLIPPING
- HARD CLIPPING
- SATURATION
- WAVESHAPING
- WAVEFOLDING
- ASYMMETRIC DISTORTION
- BITCRUSHING
- DOWNSAMPLING

THE OBJECTIVE IS TO PROVIDE A WIDE RANGE OF DISTORTION CHARACTERISTICS, FROM SUBTLE HARMONIC ENHANCEMENT TO EXTREMELY AGGRESSIVE HARD DANCE KICKS.

### 04 / FILTERING AND PROCESSING

ADDITIONAL SOUND SHAPING TOOLS FOR REFINING THE FINAL RESULT.

- FILTERING
- FREQUENCY SHAPING
- EQ CONTROL
- TONE ADJUSTMENT
- OUTPUT LEVEL CONTROL

### 05 / SAMPLE LAYERING

OPTIONAL SAMPLE INTEGRATION TO COMBINE SYNTHESIZED SOUND WITH EXTERNAL AUDIO MATERIAL.

- SAMPLE IMPORT
- SAMPLE LAYERING
- LAYER VOLUME CONTROL
- SAMPLE AND SYNTHESIS BLENDING

### 06 / WORKFLOW AND EXPORT

TOOLS DESIGNED TO MAKE KICK CREATION MORE EFFICIENT.

- PRESET MANAGEMENT
- CUSTOM PRESET SAVING
- RANDOMIZATION
- REAL-TIME WAVEFORM VISUALIZATION
- WAV EXPORT
- PARAMETER AUTOMATION

## TECHNOLOGY

JUICE BOX IS BEING DEVELOPED USING A DEDICATED AUDIO DEVELOPMENT STACK:

- **C++** FOR CORE DEVELOPMENT AND AUDIO PROCESSING.
- **JUCE** AS THE AUDIO PLUGIN FRAMEWORK.
- **CMAKE** FOR PROJECT CONFIGURATION AND BUILD MANAGEMENT.
- **VST3** AS THE TARGET PLUGIN FORMAT.
- **VISUAL STUDIO 2022** AS THE WINDOWS DEVELOPMENT ENVIRONMENT.
- **WINDOWS X64** AS THE INITIAL TARGET PLATFORM.
